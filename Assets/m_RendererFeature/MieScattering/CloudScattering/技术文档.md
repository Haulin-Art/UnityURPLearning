## 一、体积云渲染的基本原理

体积云渲染的核心目标是模拟光在云层中复杂的吸收、散射和透射行为，从而在实时渲染中呈现具有立体感和动态光照的云朵。其基本流程可概括为两个步骤：

1.  **密度计算**：沿观察方向（射线）步进，累计穿过云层的总密度，以确定云的形状和透明度。
2.  **光照计算**：在每个采样点，评估光线如何被云层吸收、散射，从而决定该点的最终颜色和亮度。

实现这一流程的主流技术是**光线步进（RayMarching）**。

## 二、核心方法详解

### 1. 密度场建模
密度场定义了空间中每一点云的密度，是决定云形状的基础。通常由多种数据源融合而成。

#### a. 3D噪声纹理
使用3D噪声纹理来程序化生成云的基础形状和细节。
*   **基础形状噪声**：通常使用一张128³的3D纹理，其R通道存储Perlin-Worley噪声，GBA通道存储三个频率递增的Worley噪声（用于FBM分形叠加）。这决定了云的大型结构。
*   **细节噪声**：使用另一张32³的3D纹理，存储三个频率递增的高频Worley噪声，用于侵蚀云边缘、添加细节，形成“花椰菜”般的billowy效果。

**伪代码：密度采样与融合**
```hlsl
// 采样基础噪声（低频）
float4 shapeNoise = tex3Dlod(_ShapeNoise, float4(worldPos / scale, mipLevel));
float lowFreqFBM = shapeNoise.g * 0.625 + shapeNoise.b * 0.25 + shapeNoise.a * 0.125;
float baseDensity = remap(shapeNoise.r, -(1 - lowFreqFBM), 1.0, 0.0, 1.0);

// 采样细节噪声（高频）
float3 detailNoise = tex3Dlod(_DetailNoise, float4(worldPos / detailScale, mipLevel));
float highFreqFBM = detailNoise.r * 0.625 + detailNoise.g * 0.25 + detailNoise.b * 0.125;
float highFreqModifier = lerp(highFreqFBM, 1 - highFreqFBM, saturate(heightPercent * _DetailParams.x));

// 使用remap将细节噪声侵蚀到基础形状上，而非简单相乘，以保持主体形状
baseDensity = remap(baseDensity, highFreqModifier * _DetailParams.y, 1.0, 0.0, 1.0);
```

#### b. 天气图（Weather Map）
一张2D纹理（通常平铺于世界XZ平面），用于宏观控制云的分布和属性。
*   **R通道**：云覆盖率（Coverage）。控制该区域是否有云及云的稀疏程度。
*   **G通道**：云类型（Cloud Type）。0.0表示层云（Stratus），0.5表示层积云（Stratocumulus），1.0表示积云（Cumulus）。这本质上是不同高度密度分布函数的插值权重。
*   **B通道**：降水概率（Precipitation）。可用于影响云的吸收率或密度。

**伪代码：应用天气图**
```hlsl
float3 weather = tex2D(_WeatherMap, worldPos.xz / _WeatherMapScale).rgb;
float coverage = weather.r;
float cloudType = weather.b; // 注意：不同文章通道定义可能不同

// 应用覆盖率
baseDensity = remap(baseDensity, 1.0 - coverage, 1.0, 0.0, 1.0);
baseDensity *= coverage;

// 根据云类型和当前高度，获取高度梯度因子
float heightGradient = GetDensityHeightGradient(heightPercent, cloudType);
baseDensity *= heightGradient;
```

#### c. 高度梯度与LUT
云密度随高度变化。可以使用预计算的查找纹理（LUT）或曲线函数来灵活控制。
*   **方法**：将归一化的高度值（0为云底，1为云顶）作为UV的V坐标，采样一张1D纹理（或2D纹理的一列），读取该高度的密度、侵蚀因子等。
*   **优点**：美术可以通过调整曲线直观地控制云在不同高度的厚薄、羽化程度，实现参数解耦。

### 2. RayMarching算法
在由云底和云顶定义的球形夹层（模拟地球大气层）中进行步进采样。

#### a. 射线-球体求交
首先计算观察射线与云层球体（地球半径+云底/云顶高度）的交点，以确定步进的起点和有效距离。

**伪代码：射线-球体求交**
```hlsl
bool RaySphereIntersect(float3 rayOrigin, float3 rayDir, float3 sphereCenter, float sphereRadius, out float t0, out float t1) {
    float3 oc = rayOrigin - sphereCenter;
    float a = dot(rayDir, rayDir);
    float b = 2.0 * dot(oc, rayDir);
    float c = dot(oc, oc) - sphereRadius * sphereRadius;
    float discriminant = b * b - 4 * a * c;
    if (discriminant < 0) return false;
    float sqrtDisc = sqrt(discriminant);
    t0 = (-b - sqrtDisc) / (2 * a);
    t1 = (-b + sqrtDisc) / (2 * a);
    // 确保 t0 < t1
    if (t0 > t1) swap(t0, t1);
    return true;
}
```

**伪代码：计算云层步进区间**
根据相机相对于云层的位置（云下、云中、云上），计算步进的起始距离 `nearT` 和步进长度 `stepLen`。

#### b. 基础RayMarching循环
在 `[nearT, farT]` 区间内，以固定步长 `stepSize` 前进，累计密度和颜色。

**伪代码：基础循环**
```hlsl
float3 pos = rayOrigin + nearT * rayDir;
float totalDensity = 0.0;
float3 totalLight = float3(0,0,0);
float transmittance = 1.0; // 透射率

for (int i = 0; i < maxSteps; i++) {
    // 1. 采样当前点的密度
    float density = SampleCloudDensity(pos);
    
    if (density > 0.01) {
        // 2. 计算当前点的光照
        float3 light = CalculateCloudLighting(pos, lightDir);
        
        // 3. 累加光照贡献（考虑透射率）
        totalLight += light * density * transmittance;
        
        // 4. 累加密度，更新透射率（Beer-Lambert定律）
        totalDensity += density;
        transmittance *= exp(-density * _AbsorptionCoefficient);
        
        // 5. 提前退出：如果透射率足够低，后续贡献可忽略
        if (transmittance < 0.01) break;
    }
    
    // 6. 步进到下一个点
    pos += rayDir * stepSize;
    if (distance traveled > farT) break;
}

// 最终颜色 = 背景色 * transmittance + totalLight
```

#### c. 跳跃式步进（Jittered / Adaptive Stepping）
优化策略：在无云区域使用大步长快速穿越，在检测到云时切换为小步长进行精细采样。
*   **实现**：维护两种步长（`largeStep`， `smallStep`）和一个“云检测”状态。大步长模式下只采样低频噪声进行快速检测；当密度大于阈值，则回退一步，切换为小步长模式进行完整的光照计算。

### 3. 光照计算
云的光照外观主要由三种物理现象构成：

#### a. 方向性散射（银边效应）
描述光线在云粒子上的散射方向分布，常用**Henyey-Greenstein相位函数**模拟。
```hlsl
float HGPhase(float cosTheta, float g) {
    float g2 = g * g;
    return (1 - g2) / (4 * PI * pow(1 + g2 - 2 * g * cosTheta, 1.5));
}
// 通常混合两个HG函数以控制前向/后向散射
float phase = lerp(HGPhase(cosTheta, g1), HGPhase(cosTheta, g2), blendWeight);
```

#### b. 吸收与外散射（光衰减）
光线在云中传播时能量衰减，遵循**Beer-Lambert定律**。
```hlsl
float beerTransmittance = exp(-density * _ExtinctionCoefficient);
```

#### c. 内散射与糖粉效应
在较厚的云层中，光线经过多次散射，可能从观察方向射出，导致云层暗边和褶皱亮边。常用改进的**Beer's Powder**函数模拟。
```hlsl
float beerPowderTransmittance = exp(-density * _ExtinctionCoefficient) * (1 - exp(-density * _PowderCoefficient));
```

#### d. 锥形采样（Cone Sampling）
为近似多重散射，在计算每个采样点的光照时，不是只向光源方向步进一次，而是在一个**锥形范围**内随机采样多个点，累加密度来估算光照遮蔽情况，使光照过渡更柔和自然。

## 三、基础实现流程总结

1.  **准备资源**：生成或获取基础形状3D噪声纹理、细节3D噪声纹理、2D天气图。
2.  **顶点/片元着色器**：在屏幕空间后处理或指定渲染Pass中执行。
3.  **计算步进区间**：根据相机位置，计算观察射线与云层球体的交点，确定 `startT` 和 `maxDist`。
4.  **RayMarching循环**：
    *   初始化位置、累计变量。
    *   循环步进：采样密度 → 若有效则计算光照并累加 → 更新透射率 → 判断提前退出。
    *   应用步长优化（跳跃式步进）。
5.  **光照计算**：在 `CalculateCloudLighting` 函数中，结合相位函数、Beer定律和粉末效应，可选锥形采样。
6.  **合成输出**：将累计的光照结果与背景颜色（根据透射率混合）结合，输出最终像素颜色。

## 四、关键伪代码概览

```hlsl
// 主函数
float4 RenderVolumetricCloud(float2 uv, float3 rayOrigin, float3 rayDir) {
    // 1. 求交，获取步进区间
    float2 cloudHitInfo = IntersectCloudSphere(rayOrigin, rayDir, _EarthCenter, _CloudBottomHeight, _CloudTopHeight);
    float startT = cloudHitInfo.x;
    float maxDist = cloudHitInfo.y;
    
    if (maxDist <= 0) return _SkyColor; // 未击中云层
    
    // 2. 初始化
    float3 pos = rayOrigin + startT * rayDir;
    float stepSize = _BaseStepSize;
    float totalDensity = 0.0;
    float3 totalLight = float3(0,0,0);
    float transmittance = 1.0;
    
    // 3. RayMarching循环
    for (int i = 0; i < _MaxSteps && totalDensity < _MaxDensity; i++) {
        // 采样密度（结合3D噪声和天气图）
        float density = SampleDensityField(pos);
        
        if (density > _DensityThreshold) {
            // 计算该点光照（包含相位函数、衰减、锥形采样）
            float3 light = ComputeSingleScattering(pos, _SunDir);
            totalLight += light * density * transmittance;
            totalDensity += density;
            transmittance *= exp(-density * _Extinction);
        }
        
        // 自适应步进（简化版）
        stepSize = (density > 0) ? _SmallStepSize : _LargeStepSize;
        pos += rayDir * stepSize;
        
        // 边界检查
        if (distance traveled > maxDist) break;
    }
    
    // 4. 合成
    float3 finalColor = _SkyColor * transmittance + totalLight;
    return float4(finalColor, 1.0 - transmittance); // Alpha可用于与场景混合
}
```
