# 体积云渲染技术规划文档

## 项目概述
基于现有的 `AtmosScatteringSkybox.shader`，添加体积云渲染功能。体积云将在同一个光线步进循环中与大气散射一起计算，以节省性能。

## 技术方案

### 核心思路
1. 使用两个嵌套球体定义云层区域（类似大气层的定义方式）
2. 在光线步进过程中，同时计算大气散射和体积云
3. 使用3D Perlin噪波生成云的密度
4. 通过Shader Feature控制是否启用体积云

### 分步骤实现计划

---

## 步骤1：创建基础Shader框架和Shader Feature

### 实现内容
- 复制原始shader创建新文件 `AtmosScatteringWithClouds.shader`
- 添加 `_VOLUMETRIC_CLOUDS` Shader Feature
- 添加云相关的基础参数（云层高度、厚度等）

### 新增参数
```hlsl
[Header(Volumetric Clouds)]
_EnableClouds ("启用体积云", Float) = 0
_CloudBottomHeight ("云层底高度(km)", Float) = 2.0
_CloudTopHeight ("云层顶高度(km)", Float) = 4.0
_CloudDensityScale ("云密度缩放", Range(0, 2)) = 1.0
```

### Debug方法
- **Debug模式0**: 显示云层区域（在云层内的区域显示为红色）
- 通过 `_DebugMode` 参数控制
- 验证云层包围盒是否正确

### 验证标准
- Shader能够正常编译
- 开启/关闭Shader Feature功能正常
- Debug模式下能正确显示云层区域

---

## 步骤2：实现3D Perlin噪波函数

### 实现内容
- 实现3D Perlin噪波生成函数
- 实现分形叠加（FBM）用于增加云的细节
- 添加噪波相关参数

### 新增参数
```hlsl
[Header(Noise Parameters)]
_CloudNoiseScale ("云噪波缩放", Float) = 1000.0
_CloudNoiseOctaves ("噪波叠加层数", Range(1, 8)) = 4
_CloudNoiseSpeed ("云移动速度", Float) = 1.0
```

### 核心函数
```hlsl
// 3D梯度噪波
float PerlinNoise3D(float3 p);

// 分形布朗运动
float FBM(float3 p, int octaves);
```

### Debug方法
- **Debug模式6**: 显示3D噪波切片（在特定高度平面上显示噪波值）
- 将噪波值映射到颜色（0-1映射到灰度）
- 可以调整 `_CloudNoiseScale` 参数观察噪波变化

### 验证标准
- 噪波函数能正确生成0-1范围的值
- 不同参数下噪波有明显变化
- Debug模式下能清晰看到噪波图案

---

## 步骤3：实现云密度采样函数

### 实现内容
- 实现云密度采样函数 `GetCloudDensity(float3 p)`
- 结合高度梯度（云层底部和顶部密度渐变）
- 结合3D噪波生成最终密度

### 核心函数
```hlsl
// 获取云密度（0-1）
float GetCloudDensity(float3 p, float3 planetCenter, float cloudBottomRadius, float cloudTopRadius);
```

### 高度梯度
- 云层底部：密度从0渐变到1
- 云层中部：密度最大
- 云层顶部：密度从1渐变到0

### Debug方法
- **Debug模式7**: 显示云密度（密度值映射到颜色）
- 使用不同颜色表示不同密度（如：低密度=蓝色，高密度=白色）
- 可以调整 `_CloudDensityScale` 参数观察密度变化

### 验证标准
- 云密度在云层外为0
- 云密度在云层内根据噪波和高度正确变化
- Debug模式下能看到云的大致形状

---

## 步骤4：整合云渲染到光线步进循环

### 实现内容
- 修改 `ComputeAtmosScattering` 函数，添加云的累积变量
- 在光线步进循环中同时采样云密度
- 计算云的光照和阴影

### 核心逻辑
```hlsl
// 在光线步进循环中
for (int i = 0; i < numSamples; i++)
{
    // 原有的大气散射计算
    // ...
    
    // 新增：云的计算
    #ifdef _VOLUMETRIC_CLOUDS
    float cloudDensity = GetCloudDensity(p, ...);
    if (cloudDensity > 0.0)
    {
        // 累积云的消光
        // 计算云的散射
        // ...
    }
    #endif
}
```

### Debug方法
- **Debug模式8**: 仅显示云层（关闭大气散射）
- **Debug模式9**: 显示云+大气散射（最终效果）
- 可以单独调整云的参数观察效果

### 验证标准
- 云能正确遮挡光线
- 云的光照效果合理（受太阳方向影响）
- 性能可接受（帧率不低于原始shader的70%）

## 步骤5：优化和参数调整

### 实现内容
- 添加云的采样数参数（独立于大气采样数）
- 添加云的颜色参数
- 优化性能（减少不必要的采样）

### 新增参数
```hlsl
[Header(Cloud Sampling)]
_CloudSamples ("云采样数", Range(4, 64)) = 16
_CloudLightSamples ("云光照采样数", Range(1, 8)) = 4

[Header(Cloud Appearance)]
_CloudColor ("云颜色", Color) = (1, 1, 1, 1)
_CloudBrightness ("云亮度", Float) = 1.0
_CloudAbsorption ("云吸收系数", Range(0, 2)) = 0.5
```

### Debug方法
- **Debug模式10**: 显示性能统计（显示采样数和帧时间）
- 对比不同参数下的性能表现
- 记录性能数据用于优化

### 验证标准
- 最终效果自然真实
- 参数可调节范围合理
- 性能满足要求

## 性能优化策略

1. **采样数分离**：云和大气的采样数独立控制
2. **早期退出**：当云密度为0时跳过计算
3. **步长调整**：在云层内使用更小的步长
4. **噪波优化**：使用更高效的噪波算法

---

## 风险和注意事项

1. **性能问题**：体积云计算量大，需要仔细优化
2. **噪波质量**：3D噪波质量直接影响云的真实感
3. **参数平衡**：云和大气的参数需要协调，避免冲突
4. **兼容性**：确保不影响原有大气散射效果
