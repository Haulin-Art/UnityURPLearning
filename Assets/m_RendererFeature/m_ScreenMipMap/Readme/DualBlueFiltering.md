Dual filter blur（双重模糊）之所以能避免降采样再升采样过程中出现的“格子状”伪影，关键在于它采用了**特定的采样模式**来模拟各向同性的模糊核，而不是简单的硬件缩放。

### 1. 为什么普通降采样/升采样会出现“格子状”？

如果直接使用GPU的双线性滤波硬件进行图像缩小再放大（即先降采样到低分辨率，再升采样回原尺寸），本质上是一种**最近邻插值**或**盒状滤波**的过程。这种操作在频域上会引入严重的**混叠（Aliasing）**，因为高频信息在降采样时被折叠到低频区域，升采样时又无法恢复原有的连续信号，导致视觉上出现明显的方块状或棋盘格图案。

### 2. Dual filter 如何实现“圆滑”效果？

Dual filter（尤其是 **Dual Kawase Blur**）通过以下两个核心设计避免了上述问题：

- **精心设计的采样模板**\
  降采样时，对每个目标像素采样**四个角点**（如图中蓝色圆点所示），这四个采样点分别位于周围四个像素的**中间位置**。这样一次采样就能通过GPU的双线性插值硬件同时获取四个像素的加权信息，相当于用一次采样代价得到了四次采样的效果。\
  升采样时，采用**各向同性（isotropic）的滤波模板**，采样点呈对称分布，确保模糊核在各个方向上响应一致，从而生成平滑的圆形光晕而非方块。
- **与Kawase模糊的继承关系**\
  Dual filter 衍生自 **Kawase模糊**，后者本身就是一种高性能模糊算法。Kawase模糊通过向四个对角方向偏移采样，并利用GPU双线性插值减少实际采样次数（从9次降至4次），在保持接近高斯模糊质量的同时大幅提升性能。Dual filter 在此基础上引入了**多分辨率金字塔**（降采样链+升采样链），进一步减少计算量，同时通过上述采样模板保持平滑性。

### 3. 简单对比

| 方法                   | 采样策略                 | 效果          | 性能            |
| -------------------- | -------------------- | ----------- | ------------- |
| 直接硬件缩放               | 双线性插值                | 易出现方块状伪影    | 高             |
| Kawase模糊             | 四角偏移采样               | 接近高斯模糊的平滑度  | 较高            |
| **Dual Kawase Blur** | **降采样/升采样 + 各向同性模板** | **圆滑的圆形光晕** | **最高（移动端优化）** |

### 总结

你链接中提到的快速Bloom方案正是利用了Dual filter的这种特性：在降采样和升采样的每一步中，通过**控制采样点的位置和权重**，使得模糊核保持圆形对称，从而避免了格子状伪影。这种设计在移动端GPU带宽受限的场景下尤为有效，既能大幅提升性能（比Unity自带Bloom快60%），又能保证视觉上的平滑度。

### 代码讲解

### 1. 降采样 Pass：收集信息

这个Pass在每次缩小图像时执行，目的是把高分辨率的信息“浓缩”到低分辨率上，同时开始混合。

```
fixed Downsample(float2 uv) {
    float2 UV;
    fixed sum;

    // 1. 中心点采样，权重是4
    sum = tex2D(_MainTex, uv) * 4.0;

    // 2. 对四个角点进行采样（左下、右上、右下、左上）
    UV = float2(uv.x - _HalfPixelX, uv.y - _HalfPixelY);
    sum += tex2D(_MainTex, UV);

    UV = float2(uv.x + _HalfPixelX, uv.y + _HalfPixelY);
    sum += tex2D(_MainTex, UV);

    UV = float2(uv.x + _HalfPixelX, uv.y - _HalfPixelY);
    sum += tex2D(_MainTex, UV);

    UV = float2(uv.x - _HalfPixelX, uv.y + _HalfPixelY);
    sum += tex2D(_MainTex, UV);

    // 3. 除以总权重8，得到平均值
    return sum * 0.125; // sum / 8.0
}
```

**关键点**：它采样了 **一个中心点 + 四个角点**。注意，角点的坐标正好位于周围四个像素的**中间**。当GPU去纹理的 `(uv.x - _HalfPixelX, uv.y - _HalfPixelY)`这个位置采样时，由于纹理坐标不精确对应像素中心，GPU的**双线性过滤硬件会自动对周围的四个像素进行加权混合**。所以，**一次** **`tex2D`调用，实际上免费获得了四个像素的混合信息**。

这个5点采样模板（中心权重4，四个角各权重1）模拟了一个圆形的、平滑的滤波核，而不是一个生硬的方块。

### 2. 升采样 Pass：扩散与混合

这个Pass在每次放大图像时执行，目的是把低分辨率的模糊结果“扩散”开，并与当前层混合，形成更平滑的过渡。

```
fixed Upsample(float2 uv) {
    float2 UV;
    fixed sum;

    // 采样一个“十字形”加四个“角点”，共8个采样点
    UV = float2(uv.x - _HalfPixelX * 2.0, uv.y); // 左
    sum = tex2D(_MainTex, UV);

    UV = float2(uv.x - _HalfPixelX, uv.y + _HalfPixelY); // 左上
    sum += tex2D(_MainTex, UV) * 2.0; // 权重2

    UV = float2(uv.x, uv.y + _HalfPixelY * 2.0); // 上
    sum += tex2D(_MainTex, UV);

    UV = float2(uv.x + _HalfPixelX, uv.y + _HalfPixelY); // 右上
    sum += tex2D(_MainTex, UV) * 2.0; // 权重2

    UV = float2(uv.x + _HalfPixelX * 2.0, uv.y); // 右
    sum += tex2D(_MainTex, UV);

    UV = float2(uv.x + _HalfPixelX, uv.y - _HalfPixelY); // 右下
    sum += tex2D(_MainTex, UV) * 2.0; // 权重2

    UV = float2(uv.x, uv.y - _HalfPixelY * 2.0); // 下
    sum += tex2D(_MainTex, UV);

    UV = float2(uv.x - _HalfPixelX, uv.y - _HalfPixelY); // 左下
    sum += tex2D(_MainTex, UV) * 2.0; // 权重2

    return sum / 12.0; // 总权重 1+2+1+2+1+2+1+2 = 12
}
```

**关键点**：这个模板是**各向同性**的（各个方向对称）。它采样了上下左右4个点（权重1），和四个对角线方向4个点（权重2）。这个形状就像一个圆形的涟漪，能够非常自然地将一个亮点的光晕向四周**平滑地扩散**，完全避免了只进行上下左右平均所带来的菱形或方块感。

### 3. C# 代码如何组织这个过程

再看你提供的 `DualFilterIterations`函数，它就像乐队的指挥：

1. **降采样阶段**：从原图开始，每次宽度高度减半，使用上面的 `Downsample`Pass进行渲染（除了第一次直接用硬件缩放，节省性能）。这样会生成一串越来越小的图像（`Mipmap`链），每一层都已经过初步平滑。
2. **升采样阶段**：从最小的图像开始，每次宽度高度加倍，使用上面的 `Upsample`Pass进行渲染（除了最后一次用硬件缩放）。每一层都会和当前更大一层的图像混合（通过Blit操作），将平滑的模糊效果逐级“传递”和“放大”回去。

**最终效果**：经过这一降一升的“金字塔”处理，一个像素的亮度信息，不是被生硬地复制到周围的方格里，而是按照 `Upsample`中那个圆形权重模板，优雅地扩散开来，形成了你看到的**圆滑光晕**。整个过程通过精心设计的采样点，欺骗性的利用了GPU硬件，用极少的采样次数（每次Pass只有4或8次`tex2D`调用）就实现了接近高斯模糊的平滑效果。
