# Planar Reflection Renderer Feature 技术规划

## 一、项目概述

本项目旨在实现一个 URP (Universal Render Pipeline) 的 Planar Reflection Renderer Feature，用于生成平面反射效果并将反射纹理设置为全局纹理，供材质 shader 使用。

## 二、实现步骤

### 步骤 1：创建 Renderer Feature 基础结构

**目标**：创建 PlanarReflectionRendererFeature 类，继承自 ScriptableRendererFeature

**实现内容**：
- 创建 PlanarReflectionRendererFeature.cs 文件
- 实现 Create() 方法，创建并初始化 PlanarReflectionPass
- 实现 AddRenderPasses() 方法，将反射渲染通道添加到渲染队列
- 添加必要的序列化字段，如反射平面、分辨率等参数

**调试方法**：
- 在 Create() 和 AddRenderPasses() 方法中添加 Debug.Log 输出
- 在 URP 渲染器中添加该 Feature，检查是否正确初始化

### 步骤 2：实现反射渲染通道 (PlanarReflectionPass)

**目标**：创建 PlanarReflectionPass 类，继承自 ScriptableRenderPass

**实现内容**：
- 实现 Execute() 方法，执行反射渲染逻辑
- 实现反射相机的创建和配置
- 计算反射矩阵和斜投影矩阵
- 渲染到 RenderTexture
- 清理临时资源

**调试方法**：
- 添加反射相机可见性控制，可通过开关查看反射相机视角
- 输出反射矩阵和相机参数到控制台
- 将反射纹理保存为资源文件，检查渲染结果

### 步骤 3：实现反射矩阵计算

**目标**：实现反射矩阵的计算功能

**实现内容**：
- 实现 CalculateReflectionMatrix() 方法
- 基于平面方程计算反射矩阵
- 处理反射相机的位置和矩阵设置

**调试方法**：
- 输出计算得到的反射矩阵到控制台
- 可视化反射相机位置与主相机的对称关系
- 验证反射点计算是否正确

### 步骤 4：实现斜投影矩阵

**目标**：实现斜投影矩阵的计算，确保反射相机只渲染平面上方的物体

**实现内容**：
- 实现 CameraSpacePlane() 方法
- 使用 CalculateObliqueMatrix() 计算斜投影矩阵
- 设置反射相机的投影矩阵

**调试方法**：
- 输出计算得到的斜投影矩阵到控制台
- 验证反射相机的裁剪平面是否正确
- 检查是否只渲染了平面上方的物体

### 步骤 5：实现全局纹理设置

**目标**：将反射纹理设置为全局纹理，供材质 shader 使用

**实现内容**：
- 在渲染完成后，将反射纹理设置为全局纹理
- 处理纹理的生命周期和资源管理

**调试方法**：
- 检查全局纹理是否正确设置
- 在材质 shader 中采样该纹理，验证是否能正确获取
- 输出纹理的分辨率和状态信息

### 步骤 6：性能优化

**目标**：优化反射渲染的性能

**实现内容**：
- 添加分辨率控制选项
- 实现更新频率控制
- 添加 LayerMask 控制，只渲染需要反射的物体
- 设置反射相机的远裁剪平面

**调试方法**：
- 测量不同分辨率下的渲染时间
- 检查更新频率是否正确生效
- 验证 LayerMask 控制是否有效

### 步骤 7：Shader 集成

**目标**：提供 shader 采样反射纹理的示例

**实现内容**：
- 创建示例材质和 shader
- 实现反射纹理的采样逻辑
- 添加菲涅尔效应和反射强度控制

**调试方法**：
- 测试材质是否能正确采样反射纹理
- 调整参数，观察反射效果的变化
- 验证菲涅尔效应是否正确实现

## 三、技术要点

1. **反射矩阵计算**：基于平面方程的反射矩阵推导
2. **斜投影矩阵**：确保反射相机只渲染平面上方的物体
3. **URP 渲染流程**：正确集成到 URP 的渲染管线中
4. **资源管理**：合理管理 RenderTexture 和相机资源
5. **性能优化**：通过分辨率、更新频率等参数控制性能开销

## 四、预期效果

- 水面、镜面等平面物体能正确显示环境反射
- 反射效果实时更新，响应场景变化
- 性能开销可控，适合实时渲染
- 提供直观的参数控制界面

## 五、风险评估

1. **性能风险**：高分辨率反射可能导致性能下降
   - 缓解措施：提供分辨率控制和更新频率选项

2. **实现复杂度**：涉及矩阵计算和 URP 渲染流程
   - 缓解措施：详细的代码注释和调试方法

3. **兼容性问题**：不同 URP 版本可能有差异
   - 缓解措施：使用通用的 URP API，避免版本特定功能

## 六、测试计划

1. **基础功能测试**：验证反射效果是否正确
2. **性能测试**：测量不同设置下的性能开销
3. **边界情况测试**：测试不同角度、距离下的反射效果
4. **集成测试**：与其他 URP Feature 配合使用
