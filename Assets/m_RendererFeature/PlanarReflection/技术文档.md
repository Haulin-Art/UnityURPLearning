# Unity URP平面反射技术文档

## 一、核心原理

平面反射（Planar Reflection）通过创建虚拟反射相机来模拟镜面效果。基本原理是：在反射平面对称位置创建一个相机，渲染场景得到倒影图像，然后将该图像应用到反射表面（如水面）上。

**关键数学工具**：反射矩阵（Reflection Matrix）

- 基于平面方程：`np + d = 0`（n为平面法向量，d为常数）
- 对称点计算公式：`P' = P - 2(P·n + d)n`
- 反射矩阵将点P变换为关于平面的对称点P'网页

## 二、反射矩阵推导

### 2.1 数学推导

已知平面单位法向量`N(x_n, y_n, z_n)`，平面上任意点`P_0(x_0, y_0, z_0)`，平面外点`P(x, y, z)`，其对称点`P'(x', y', z')`满足：

```
x' = (1 - 2x_n²)x - 2y_nx_n·y - 2z_nx_n·z - 2x_n·d
y' = -2x_ny_n·x + (1 - 2y_n²)y - 2z_ny_n·z - 2y_n·d  
z' = -2x_nz_n·x - 2y_nz_n·y + (1 - 2z_n²)z - 2z_n·d
```

其中`d = -(x_nx_0 + y_ny_0 + z_nz_0)`网页

### 2.2 Unity实现代码

```csharp
static void CalculateReflectionMatrix(ref Matrix4x4 reflectionMat, Vector4 plane)
{
    reflectionMat.m00 = (1F - 2F * plane[0] * plane[0]);
    reflectionMat.m01 = (-2F * plane[0] * plane[1]);
    reflectionMat.m02 = (-2F * plane[0] * plane[2]);
    reflectionMat.m03 = (-2F * plane[3] * plane[0]);
    
    reflectionMat.m10 = (-2F * plane[1] * plane[0]);
    reflectionMat.m11 = (1F - 2F * plane[1] * plane[1]);
    reflectionMat.m12 = (-2F * plane[1] * plane[2]);
    reflectionMat.m13 = (-2F * plane[3] * plane[1]);
    
    reflectionMat.m20 = (-2F * plane[2] * plane[0]);
    reflectionMat.m21 = (-2F * plane[2] * plane[1]);
    reflectionMat.m22 = (1 - 2F * plane[2] * plane[2]);
    reflectionMat.m23 = (-2F * plane[3] * plane[2]);
    
    reflectionMat.m30 = 0F;
    reflectionMat.m31 = 0F;
    reflectionMat.m32 = 0F;
    reflectionMat.m33 = 1F;
}
```

## 三、URP实现方案

### 3.1 基本步骤

1. **创建反射相机**：复制主相机参数，定位到对称位置
2. **计算反射矩阵**：基于反射平面方程
3. **设置斜投影矩阵**：裁剪平面以下部分
4. **渲染到RenderTexture**：反射相机渲染结果
5. **Shader采样**：在水面Shader中采样反射纹理网页

### 3.2 关键实现细节

#### 3.2.1 反射相机设置

```csharp
// 计算反射平面
Vector3 planeNormal = transform.up;
Vector3 planePosition = transform.position;
float d = -Vector3.Dot(planeNormal, planePosition);
Vector4 reflectionPlane = new Vector4(planeNormal.x, planeNormal.y, planeNormal.z, d);

// 计算反射矩阵
Matrix4x4 reflectionMatrix = Matrix4x4.identity;
CalculateReflectionMatrix(ref reflectionMatrix, reflectionPlane);

// 设置反射相机位置和矩阵
Vector3 reflectedPos = reflectionMatrix.MultiplyPoint(mainCamera.transform.position);
reflectionCamera.transform.position = reflectedPos;
reflectionCamera.worldToCameraMatrix = mainCamera.worldToCameraMatrix * reflectionMatrix;
```

#### 3.2.2 斜投影矩阵（Oblique Projection）

反射相机需要以反射平面为近平面，只渲染平面上方部分，避免看到平面背后的物体\[web:5]。

```csharp
// 计算相机空间平面
private Vector4 CameraSpacePlane(Camera cam, Vector3 pos, Vector3 normal, float sideSign)
{
    Vector3 offsetPos = pos + normal * clipPlaneOffset;
    Matrix4x4 m = cam.worldToCameraMatrix;
    Vector3 cpos = m.MultiplyPoint(offsetPos);
    Vector3 cnormal = m.MultiplyVector(normal).normalized * sideSign;
    return new Vector4(cnormal.x, cnormal.y, cnormal.z, -Vector3.Dot(cpos, cnormal));
}

// 计算斜投影矩阵
Vector4 clipPlane = CameraSpacePlane(reflectionCamera, planePosition - planeNormal * clipPlaneOffset, planeNormal, 1.0f);
Matrix4x4 projection = mainCamera.CalculateObliqueMatrix(clipPlane);
reflectionCamera.projectionMatrix = projection;
```

#### 3.2.3 剔除方向翻转

```csharp
GL.invertCulling = true;  // 开始渲染前翻转剔除
UniversalRenderPipeline.RenderSingleCamera(context, reflectionCamera);
GL.invertCulling = false; // 渲染完成后恢复
```

## 四、Shader实现

### 4.1 反射纹理采样

```hlsl
TEXTURE2D(_ReflectionTex);
SAMPLER(sampler_ReflectionTex);

// 计算反射UV
float2 GetReflectionUV(float3 worldPos, float3 worldNormal)
{
    // 将世界坐标转换到反射相机投影空间
    float4 reflectionClipPos = mul(_ReflectionVP, float4(worldPos, 1.0));
    float2 reflectionUV = reflectionClipPos.xy / reflectionClipPos.w;
    reflectionUV = reflectionUV * 0.5 + 0.5;
    
    // 应用菲涅尔效应
    float3 viewDir = normalize(_WorldSpaceCameraPos - worldPos);
    float fresnel = pow(1.0 - saturate(dot(worldNormal, viewDir)), _FresnelPower);
    
    return reflectionUV;
}
```

### 4.2 水面反射合成

```hlsl
// 采样反射纹理
float4 reflectionColor = SAMPLE_TEXTURE2D(_ReflectionTex, sampler_ReflectionTex, reflectionUV);

// 结合水面颜色和反射
float4 finalColor = lerp(waterColor, reflectionColor, reflectionStrength * fresnel);
```

## 五、性能优化建议

1. **分辨率控制**：使用半分辨率或更低分辨率的RenderTexture
2. **更新频率**：每2-3帧更新一次反射纹理
3. **渲染层控制**：通过LayerMask只渲染需要反射的物体
4. **距离裁剪**：设置反射相机的远裁剪平面，避免渲染过远物体
5. **LOD优化**：为反射相机使用更低的LOD级别

## 六、常见问题与解决方案

| 问题          | 原因         | 解决方案                                    |
| ----------- | ---------- | --------------------------------------- |
| 反射出现平面背后的物体 | 未正确设置斜投影矩阵 | 使用CalculateObliqueMatrix计算斜投影矩阵\[web:5] |
| 反射图像翻转不正确   | 反射矩阵计算错误   | 检查平面法向量和位置计算                            |
| 性能开销过大      | 全分辨率渲染所有物体 | 降低分辨率、限制更新频率、使用LayerMask                |
| 边缘锯齿        | 纹理采样问题     | 使用双线性或三线性过滤，添加边缘柔化                      |

4. **建筑反射**：玻璃幕墙、大理石地面
