# 浅水方程模拟开发规划

## 项目概述
基于Compute Shader实现浅水方程模拟，用于在RenderTexture上模拟水面波纹效果。

## 浅水方程核心原理

### 基本方程
```
∂h/∂t + ∇·(hv) = 0          // 质量守恒（高度连续性）
∂v/∂t + (v·∇)v = -g∇h - γv  // 动量守恒
```

### 简化实现步骤
1. **速度平流**：速度场随自身移动
2. **高度平流**：高度场随速度移动
3. **压力项**：高度梯度影响速度（产生波纹扩散）
4. **边界条件**：处理边缘反射/吸收

### 步骤3：压力项与恢复力（完整浅水方程）✅（已完成）
**目标**：实现完整的浅水方程模拟，产生振荡波纹

**实现内容**：
- 计算高度梯度 ∇h（中心差分）
- 压力项：v += -k₁ * ∇h（高度梯度影响速度）
- 恢复力：v += -k₂ * h（高度围绕平衡点振荡）
- 连续性方程：h += -∇·v（速度散度影响高度）
- 新增参数 `pressureStrength` 和 `restoreStrength`

**物理原理**：
```
振荡循环：
高度隆起 → 向外速度（压力项）
向外速度 → 高度下降（连续性方程）
高度下降 → 向内速度（压力项）
向内速度 → 高度上升（连续性方程）
→ 形成振荡波纹！
```

**可测试内容**：
- [x] 高度隆起产生向外的速度
- [x] 波纹向外扩散并振荡
- [x] 调节压力强度影响扩散速度
- [x] 调节恢复力影响振荡频率

**预期效果**：
能看到同心圆波纹从源位置向外扩散，并产生振荡效果

## 参数设计

### 模拟参数
| 参数名 | 说明 | 默认值 | 范围 |
|--------|------|--------|------|
| dt | 时间步长 | 0.016 | 0.001 - 0.1 |
| advectSpeed | 平流速度 | 1.0 | 0 - 5 |
| damping | 衰减系数 | 0.01 | 0 - 0.5 |

| restoreStrength | 恢复力强度 | 0.1 | 0 - 1 |

### 源参数
| 参数名 | 说明 | 默认值 |
|--------|------|--------|
| sourcePos | 源位置（UV） | (0.5, 0.5) |
| sourceRadius | 源半径（UV） | 0.05 |
| velocityStrength | 速度强度 | 1.0 |
| heightStrength | 高度强度 | 1.0 |
| moveSpeed | WASD移动速度 | 0.5 |
