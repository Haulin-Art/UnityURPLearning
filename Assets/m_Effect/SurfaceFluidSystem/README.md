# 表面流体系统 (Surface Fluid System)

基于浅水方程的表面流体模拟系统，支持任意曲面上流体的真实感模拟。

## 核心原理

### 浅水方程

本系统基于浅水方程（Shallow Water Equations）实现流体模拟：

**连续性方程**（质量守恒）：

```
∂h/∂t + ∇·(hv) = 0
```

**动量方程**（动量守恒）：

```
∂v/∂t + (v·∇)v = -g∇η - friction·v
```

其中：

- `h` = 水深
- `v` = 速度场
- `η = h + b` = 水面高度（水深 + 床底高度）
- `g` = 重力加速度
- `friction` = 摩擦系数

***

### 核心技术：切向空间流体模拟

#### 问题背景

当在任意曲面上进行流体模拟时，面临两个核心挑战：

1. **UV展开问题**：模型的UV展开会将3D曲面分割成多个UV岛，流体无法自然跨越UV岛边界流动
2. **重力方向问题**：在曲面上，重力方向需要转换到切向空间，才能正确驱动流体沿表面流动

#### 解决方案：UV岛邻接图 + 切向空间重力图

本系统通过以下机制实现跨UV岛的切向空间流体模拟：

```
┌────────────────────────────────────────────────────────────────┐
│                    每帧模拟流程                                 │
├────────────────────────────────────────────────────────────────┤
│                                                                │
│  1. 浅水方程计算（在UV空间内）                                   │
│     ├── 平流项：半拉格朗日法回溯                                 │
│     ├── 动量方程：重力驱动 + 摩擦力 + 表面张力                    │
│     └── 连续性方程：通量散度                                     │
│                                                                │
│  2. UV岛边界处理（核心！）                                       │
│     ├── 从UV岛邻接图获取邻接信息                                 │
│     ├── 将邻接UV岛的数据复制到边缘外围区域                        │
│     └── 矫正速度场方向到重力方向                                  │
│                                                                │
│  3. 输出                                                        │
│     ├── 流体数据图（RG=速度, B=高度）                            │
│     └── 法线图（根据水高梯度计算）                                │
│                                                                │
└────────────────────────────────────────────────────────────────┘
```

#### UV岛边界处理详解

**核心思想**：在UV岛的边缘外围区域（描边区域），存储邻接UV岛对应位置的数据，实现跨岛数据传递。

**UV岛邻接图格式**：

| 通道 | 内容     | 说明                  |
| -- | ------ | ------------------- |
| R  | 邻接UV.x | 邻接位置的目标UV坐标         |
| G  | 邻接UV.y | 邻接位置的目标UV坐标         |
| B  | 边缘遮罩   | 是否为UV岛边缘（0或1）       |
| A  | UV岛范围  | UV岛内部区域（边缘内为1，外围为0） |

**边界处理算法**（Compute Shader实现）：

```hlsl
// 1. 采样UV岛邻接图
float4 jump_factor = UVJumpMap.SampleLevel(samplerLinearClamp, uv, 0);
// jump_factor.xy = 邻接目标UV
// jump_factor.z  = 边缘遮罩
// jump_factor.a  = UV岛范围

// 2. 计算跳跃遮罩
// jump_mask = 1 表示在边缘外围区域，需要从邻接位置获取数据
float jump_mask = jump_factor.z * (1.0 - jump_factor.a);

// 3. 从邻接UV位置采样流体数据
float3 jump_data = FluidTex.SampleLevel(samplerLinearClamp, jump_factor.xy, 0);
float jump_height = jump_data.z;    // 邻接位置的水深
float2 jump_vel = jump_data.xy;     // 邻接位置的速度

// 4. 高度混合：在边缘外围区域使用邻接位置的高度
new_height = lerp(new_height, max(jump_height, new_height), jump_mask);

// 5. 速度矫正：将速度方向重映射为重力方向
// 保持速度大小，但方向改为重力方向
float2 redirected_vel = length(jump_vel) * gravityDir;
new_vel = lerp(new_vel, redirected_vel, jump_mask);
```

**为什么需要速度矫正？**

当流体从一个UV岛流到另一个UV岛时，速度场在UV空间中的方向可能与实际曲面上的流动方向不一致。通过将速度方向重映射到重力方向，可以确保流体继续沿曲面正确流动。

```
UV空间视角：                    曲面空间视角：
┌─────────┐                    ╭─────────╮
│  UV岛A  │                    │  曲面A  │
│    →    │  跳跃后             │    ↓    │
├─────────┤  ───────>          │    ↓    │  实际流动
│  UV岛B  │                    ├─────────┤
│         │                    │  曲面B  │
└─────────┘                    ╰─────────╯
   速度方向需矫正               重力方向才是正确流向
```

#### 切向空间重力图

**作用**：将世界空间重力转换到每个点的切向空间，为流体提供正确的驱动力。需要格外注意，必须设置描边外扩，必须使其范围完整包括UV岛邻接图的范围

**格式**：

| 通道 | 内容    | 说明                       |
| -- | ----- | ------------------------ |
| R  | 重力x分量 | 切线方向分量（范围0~~1，映射到-1~~1）  |
| G  | 重力y分量 | 副切线方向分量（范围0~~1，映射到-1~~1） |

**在浅水方程中的应用**：

```hlsl
// 1. 获取切向空间重力方向
float2 gravityDir = GravityMap.SampleLevel(samplerLinearClamp, uv, 0).xy;
gravityDir = gravityDir * 2.0 - 1.0;  // 映射到[-1,1]

// 2. 在动量方程中应用重力
new_vel = ad_vel 
        - surface_gradient * gravityStrength * dt    // 水面梯度驱动
        + gravityDir * gravityStrength * dt * extraGravityStrength;  // 重力方向力
```

### 辅助技术

#### 床底高度图 (Bed Height Map)

**作用**：模拟地形起伏，使水流形成自然的水道和股流效果。

**原理**：通过噪波图模拟河床地形，水流会在低洼处聚集，形成一股一股的自然效果。

## 使用流程

### 1. 生成必要贴图

#### 生成UV岛邻接图

1. 打开工具窗口：`Tools > UV Island Adjacency Map`
2. 选择目标Mesh
3. 设置分辨率（推荐1024）
4. 点击生成，输出到 `GeneContent/` 目录

#### 生成切向空间重力图

1. 打开工具窗口：`Tools > Tangent Space Gravity Map`
2. 选择目标Mesh
3. 设置重力方向（默认向下）
4. 点击生成，输出到 `GeneContent/` 目录

### 2. 配置流体模拟

1. 创建物体并添加 `ShallowFluidSimulation` 组件
2. 设置以下参数：
   - `computeShader`：指定 `ShallowFluid.compute`
   - `uvJumpMap`：指定生成的UV岛邻接图
   - `gravityMap`：指定生成的切向空间重力图
   - `bedHeightMap`：（可选）指定噪波图形成水流

### 3. 配置射线检测

1. 添加 `RaycastTargetDetector` 组件
2. 设置目标物体数组
3. 在 `ShallowFluidSimulation` 中关联射线检测器

### 4. 配置输出

1. 创建RenderTexture作为输出：
   - `outputTexture`：流体数据图
   - `normalOutputTexture`：法线图
2. 在材质中使用这些贴图

## 参数说明

### 物理参数

| 参数                   | 默认值   | 范围     | 说明               |
| -------------------- | ----- | ------ | ---------------- |
| surfaceTension       | 0.01  | 0\~1   | 表面张力系数，控制水面聚拢程度  |
| extraGravityStrength | 0.3   | 0\~2   | 额外重力系数，控制重力方向力强度 |
| friction             | 0.002 | 0\~0.1 | 摩擦力系数，控制水流减速     |

### 床底高度参数

| 参数                        | 默认值 | 范围    | 说明        |
| ------------------------- | --- | ----- | --------- |
| bedHeightScale            | 0.1 | 0\~5  | 床底高度缩放系数  |
| bedTiling                 | 8   | 1\~32 | 床底高度图平铺次数 |
| bedAttenFactor            | 5   | 0\~20 | 床底衰减系数    |
| gapAttenuationEnhancement | 10  | 1\~20 | 接缝处衰减增强系数 |

### 模拟参数

| 参数                  | 默认值   | 范围     | 说明     |
| ------------------- | ----- | ------ | ------ |

## 注意事项

1. **贴图尺寸**：UV邻接图和重力图的尺寸应与流体模拟尺寸一致
2. **UV展开**：目标Mesh需要有正确的UV展开
3. **性能优化**：纹理格式使用RG16B16\_SFloat，采样次数已优化至6次
4. **重力方向**：重力图的方向是始终作用的力，会持续影响流体
