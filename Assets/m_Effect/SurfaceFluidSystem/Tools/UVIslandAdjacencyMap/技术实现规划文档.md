# Unity UV岛邻接图生成工具 - 技术实现规划

## 1. 项目概述

### 1.1 目标
在Unity中开发一个工具，根据网格物体(Mesh)数据生成**UV邻接纹理**，用于表面流体模拟时实现跨UV岛的无缝流动。

### 1.2 输入与输出

| 项目 | 内容 |
|------|------|
| **输入** | Unity Mesh（顶点、三角形索引、UV坐标） |
| **输出** | UV邻接纹理，支持PNG、EXR、RenderTexture三种格式 |

### 1.3 应用场景
- 表面流体/纹理跨UV岛流动
- UV岛跳跃效果（UV Island Hopping）
- 无接缝程序化纹理生成

---

## 2. 输出效果详解

### 2.1 纹理编码格式

| 通道 | 内容 | 说明 |
|------|------|------|
| **R** | 邻接UV.x | 邻接岛对应位置的UV坐标X分量 |
| **G** | 邻接UV.y | 邻接岛对应位置的UV坐标Y分量 |
| **B** | 邻接边缘遮罩 | 1=有邻接信息，0=无邻接信息 |
| **A** | UV岛范围遮罩 | 1=在UV岛内，0=在UV岛外 |

### 2.2 输出格式说明

| 格式 | 精度 | 用途 | 注意事项 |
|------|------|------|----------|
| **PNG** | 8位 | 预览、调试 | 兼容性好，精度较低 |
| **EXR** | 32位浮点 | 生产环境 | 需关闭压缩以正确显示A通道 |
| **RenderTexture** | 32位浮点 | 运行时使用 | 每次生成前建议删除旧的RT |

### 2.3 着色器使用示例

```hlsl
// 采样邻接图
float4 adjacencyData = _AdjacencyMap.Sample(sampler, uv);

// 解析数据
float2 adjacentUV = adjacencyData.rg;      // 邻接UV坐标
float hasAdjacency = adjacencyData.b;       // 邻接边缘遮罩
float inUVIsland = adjacencyData.a;         // UV岛范围遮罩

if (hasAdjacency > 0)
{
    // 采样邻接岛的颜色并混合
    float4 adjacentColor = _MainTex.Sample(sampler, adjacentUV);
    color = lerp(color, adjacentColor, _BlendStrength);
}
```

## 3. 核心算法

### 3.1 关键洞察

Unity Mesh的UV接缝处，顶点会被分裂成多个不同索引的顶点，但它们在3D空间中位置相同。

```
三角形A的边: 顶点(5, 8)  UV坐标(uv1, uv2)
三角形B的边: 顶点(8, 5)  UV坐标(uv3, uv4)
                    ↓
         3D位置相同 = 同一条边
                    ↓
         UV坐标不同 = UV接缝 = 需要记录邻接关系！
```

### 3.2 算法流程

```
Step 1: 提取所有边
  - 遍历所有三角形，记录每条边
  - 存储：顶点索引、3D位置、UV坐标、所属三角形

Step 2: 按3D位置分组
  - 使用3D位置中点的hash作为分组key
  - 同一3D位置的边归为一组

Step 3: 识别UV接缝
  - 每组中UV不连续的边对 = UV接缝
  - 建立全局顶点映射确保一致性

Step 4: 烘焙到纹理
  - 光栅化UV三角形到纹理（A通道）
  - 在边缘像素写入邻接UV信息（RG通道）
  - 标记邻接边缘遮罩（B通道）
```

### 3.3 全局顶点映射

使用BFS传播确保共享顶点的边使用一致的映射方向：


## 5. 核心类说明

### 5.1 UVAdjacencyMapBuilder

```csharp
public static class UVAdjacencyMapBuilder
{
    // 边信息
    public struct EdgeInfo {
        int vertexA, vertexB;      // 顶点索引
        int triangleIndex;          // 所属三角形
        int localEdgeIndex;         // 边索引(0,1,2)
        Vector2 uvA, uvB;           // UV坐标
        Vector3 posA, posB;         // 3D位置
    }
    
    // 接缝邻接信息
    public struct SeamAdjacency {
        EdgeInfo edgeA, edgeB;      // 邻接的两条边
        int islandA, islandB;       // 所属UV岛ID
        bool reversedMapping;       // 映射方向
    }
    
    // 主构建方法
    public static BuildResult Build(Mesh mesh, int uvChannel, float uvEpsilon);
}
```

```csharp
public class UVAdjacencyMapBaker
```

## 6. 调试功能

### 6.1 LogStatistics
输出统计信息：顶点数、三角形数、边数、接缝数、UV岛数等

### 6.2 LogSeamDetails
输出每条接缝的详细信息：边A/B的UV坐标、顶点对应关系

### 6.3 VisualizeInScene
在Scene视图中绘制：
- 红色线条：UV接缝位置
- 蓝色连线：邻接边对
- 绿色点：UV岛中心

## 7. 已知问题与注意事项

| 问题 | 解决方案 |
|------|----------|
| EXR的A通道不显示 | 关闭EXR压缩 |
| RenderTexture显示黑色 | 每次生成前删除旧的RT |
| UV接缝检测不准确 | 调整uvEpsilon参数 |
| 边缘像素遗漏 | 增加edgePadding参数 |
