# 运行时切线空间重力图生成工具 - 技术规划文档

## 1. 项目概述

### 1.1 目标
开发一个GPU驱动的运行时切线空间重力图生成工具，支持动态网格实时更新。

### 1.2 与烘焙版本的区别

| 特性 | 烘焙版本 | 运行时版本 |
|------|----------|------------|
| 计算位置 | CPU | GPU Compute Shader |
| 更新频率 | 一次性烘焙 | 实时/按需更新 |
| 适用场景 | 静态网格 | 动态变形网格（如蒙皮网格） |
| 性能 | 烘焙时耗时，运行时无开销 | 每帧有GPU计算开销 |

### 1.3 文件结构

```
RuntimeGravityMap/
├── 技术规划文档.md
├── Runtime/
│   ├── RuntimeGravityMap.Runtime.asmdef
│   ├── RuntimeGravityMapGenerator.cs    # 运行时管理组件

└── Editor/
    ├── RuntimeGravityMap.Editor.asmdef

```

## 2. 核心算法

### 2.1 GPU并行计算策略

```
每个线程处理一个像素：
- 线程ID = 像素坐标 (x, y)
- UV坐标 = (x + 0.5) / resolution, (y + 0.5) / resolution

计算流程：
1. 根据UV查找对应三角形（使用BVH加速）
2. 计算重心坐标
3. 插值法线和切线
4. 计算切线空间重力方向
5. 写入输出纹理
```

### 2.2 三角形查找优化

由于GPU不适合动态分支和复杂数据结构，采用以下策略：

**方案A：暴力遍历（简单，适合低面数网格）**
```hlsl
// 遍历所有三角形，找到包含UV的那个
for (uint triIndex = 0; triIndex < triangleCount; triIndex++)
{
    if (IsPointInTriangle(uv, triIndex))
    {
        // 找到了
        break;
    }
}
```

**方案B：网格空间索引（推荐，适合高面数网格）**
```hlsl
// 预先将UV空间划分为网格
// 每个网格单元存储可能覆盖它的三角形列表
// 查找时只检查对应网格单元的三角形
```

### 2.3 输出格式

与烘焙版本保持一致：

| 通道 | 内容 | 说明 |
|------|------|------|
| R | 流动方向X | 切线方向的流动分量 |
| G | 流动方向Y | 副切线方向的流动分量 |
| B | 流动强度 | 原始强度值 |
| A | 有效区域 | 1=有效, 0=无效 |

## 3. 分步骤实现计划

### Phase 1: 基础Compute Shader
**目标**：实现最基础的GPU计算

**步骤**：
1. 创建 `GravityMapBaker.compute`
2. 实现网格数据结构（StructuredBuffer）
3. 实现UV到三角形查找（暴力遍历）
4. 实现重心坐标计算
5. 实现切线空间重力计算

**Debug方法**：
- `DebugMode.None`: 正常输出
- `DebugMode.OutputUV`: 输出UV坐标作为颜色
- `DebugMode.OutputTriangleIndex`: 输出三角形索引作为颜色
- `DebugMode.OutputNormal`: 输出插值后的法线

### Phase 2: 运行时管理组件
**目标**：创建C#组件管理GPU计算

**步骤**：
1. 创建 `RuntimeGravityMapGenerator` 组件
2. 实现网格数据上传到GPU
3. 实现RenderTexture管理
4. 实现更新触发机制

**Debug方法**：
- 在Inspector显示上次更新耗时
- 在Scene视图绘制方向箭头
- 输出统计信息到控制台

### Phase 3: 性能优化
**目标**：优化高面数网格的性能

**步骤**：
1. 实现网格空间索引
2. 实现增量更新（可选）
3. 支持LOD分级分辨率

**Debug方法**：
- 性能分析面板
- 显示实际处理的三角形数

### Phase 4: 蒙皮网格支持
**目标**：支持SkinnedMeshRenderer

**步骤**：
1. 实现骨骼变换后的网格数据获取
2. 支持每帧自动更新
3. 支持更新频率控制

**Debug方法**：
- 显示当前骨骼状态
- 对比静态网格和蒙皮网格的结果

## 5. C# 组件结构

```csharp
namespace RuntimeGravityMap
{
    /// <summary>
    /// 调试模式
    /// </summary>
    public enum DebugMode
    {
        None,               // 正常输出
        OutputUV,           // 输出UV坐标
        OutputTriangleIndex,// 输出三角形索引
        OutputNormal,       // 输出法线
        OutputTangent,      // 输出切线
        OutputRawGravity    // 输出原始重力方向
    }

    /// <summary>
    /// 更新模式
    /// </summary>
    public enum UpdateMode
    {
        Manual,             // 手动更新
        EveryFrame,         // 每帧更新
        Interval,           // 定时更新
        OnTransformChange   // 变换改变时更新
    }

    /// <summary>
    /// 运行时重力图生成器
    /// </summary>
    public class RuntimeGravityMapGenerator : MonoBehaviour
    {
        // 配置参数
        [SerializeField] private int resolution = 256;
        [SerializeField] private Vector3 gravity = Vector3.down;
        [SerializeField] private UpdateMode updateMode = UpdateMode.Manual;
        [SerializeField] private float updateInterval = 0.1f;
        [SerializeField] private DebugMode debugMode = DebugMode.None;
        
        // 输出
        public RenderTexture GravityMap { get; private set; }
        
        // 公共方法
        public void UpdateGravityMap();
        public void SetGravity(Vector3 newGravity);
    }
}
```

## 7. 与现有系统的集成

### 7.1 使用方式

```csharp
// 在流体系统中使用
public class ShallowFluidSimulation : MonoBehaviour
{
    public RuntimeGravityMapGenerator gravityMapGenerator;
    
    void Update()
    {
        // 获取实时生成的重力图
        RenderTexture gravityMap = gravityMapGenerator.GravityMap;
        
        // 传递给流体计算
        fluidCompute.SetTexture(kernel, "_GravityMap", gravityMap);
    }
}
```

### 7.2 Shader采样

```hlsl
// 与烘焙版本相同的采样方式
float4 gravityData = _GravityMap.Sample(sampler, uv);
float2 flowDir = gravityData.xy;
float intensity = gravityData.z;
float isValid = gravityData.w;
```

## 8. 注意事项

1. **网格数据要求**：必须有法线、切线和UV数据
2. **UV要求**：UV应在[0,1]范围内，不支持平铺UV
3. **性能权衡**：高分辨率+高面数网格会有较大GPU开销
4. **蒙皮网格**：需要每帧从CPU获取变换后的顶点数据，有一定开销
