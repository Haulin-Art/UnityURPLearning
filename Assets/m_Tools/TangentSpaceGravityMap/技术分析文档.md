# 切线空间重力图生成工具 - 技术分析文档

## 1. 问题背景

### 1.1 为什么需要重力图？

在表面流体模拟中，流体需要知道"往哪个方向流动"。对于任意曲面（如角色身体、地形、物体表面），流体应该沿着表面向下流动，即沿着"下坡方向"流动。

**核心问题**：如何告诉流体在表面每个位置应该往哪个方向流动？

### 1.2 直接方案的问题

**方案1：运行时计算**
```hlsl
// 在Shader中实时计算
float3 worldGravity = float3(0, -1, 0);
float3 flowDir = worldGravity - normal * dot(worldGravity, normal);
```
- 问题：需要法线贴图，计算量大，不精确

**方案2：预烘焙世界空间方向**
- 问题：方向是世界空间，但流体模拟在UV空间进行，无法直接使用

**方案3：预烘焙切线空间方向（本工具）**
- 优点：方向在UV空间可直接使用，精度高，运行时开销小

## 2. 核心概念

### 2.1 坐标空间

```
世界空间 (World Space)
    ↓ 模型变换
模型空间 (Object Space)
    ↓ 视图变换
视图空间 (View Space)
    ↓ 投影变换
裁剪空间 (Clip Space)

切线空间 (Tangent Space) ← 本工具关注
    - 以表面为基准的局部坐标系
    - X轴：切线方向（沿UV的U方向）
    - Y轴：副切线方向（沿UV的V方向）
    - Z轴：法线方向（垂直于表面）
```

### 2.2 TBN矩阵

TBN矩阵是切线空间到世界空间的变换矩阵：

```
TBN = | Tx Bx Nx |
      | Ty By Ny |
      | Tz Bz Nz |

其中：
- T (Tangent): 切线，沿UV的U方向
- B (Bitangent): 副切线，沿UV的V方向
- N (Normal): 法线，垂直于表面
```

**重要性质**：TBN是正交矩阵，其逆矩阵等于转置矩阵。

```
TBN^(-1) = TBN^T
```

### 2.3 UV空间与切线空间的关系

```
UV空间 (2D)              切线空间 (3D)
┌─────────┐              ┌─────────┐
│    V    │              │    B    │
│    ↑    │              │    ↑    │
│    │    │     对应     │    │    │
│    │    │   ───────►   │    │    │
│    └──► U│              │    └──► T
└─────────┘              └─────────┘

UV的U方向 = 切线方向 T
UV的V方向 = 副切线方向 B
```

## 3. 算法原理

### 3.1 两种输出模式

#### 模式1：切线空间重力方向

**定义**：世界空间重力在切线空间三个轴上的分量。

**计算公式**：
```
G_tangent = TBN^T × G_world
         = (G·T, G·B, G·N)

其中：
- G·T = 重力在切线方向的分量
- G·B = 重力在副切线方向的分量
- G·N = 重力在法线方向的分量
```

**物理意义**：
- 如果表面完全水平（法线朝上），则 G·N = -1，G·T = G·B = 0
- 如果表面完全垂直，则 G·N = 0，G·T 或 G·B 有值

**问题**：方向取决于UV展开方式。不同的UV展开会导致不同的切线方向，从而得到不同的结果。

#### 模式2：表面流动方向（推荐）

**定义**：流体在表面上的实际流动方向（下坡方向）。

**计算公式**：
```
步骤1：计算重力在切平面上的投影
       G_proj = G - (G·N) × N

步骤2：将投影转换到切线空间
       flow_x = G_proj · T
       flow_y = G_proj · B

步骤3：归一化并输出
       flow_dir = normalize(float2(flow_x, flow_y))
       intensity = length(float2(flow_x, flow_y))
```

**物理意义**：
- 投影去掉了重力垂直于表面的分量
- 只保留"沿表面流动"的分量
- 与UV展开无关，只取决于表面朝向

**几何解释**：
```
        世界重力 G (0, -1, 0)
              ↓
        ┌─────┼─────┐
        │     │     │
        │     N     │  ← 法线
        │    ╱│╲    │
        │   ╱ │ ╲   │
        │  ╱  │  ╲  │
        │ ╱   │   ╲ │
        │╱────┼────╲│
        │     │     │
        │     │     │
        └─────┼─────┘
              ↓
        G_proj = G - (G·N)×N
        （重力在切平面上的投影）
```

### 3.2 为什么表面流动方向更好？

**示例**：一个倾斜的平面

```
侧视图：
        
        ┌───────────┐
       ╱│           │
      ╱ │           │
     ╱  │           │
    ╱   │           │
   ╱    └───────────┘
  ╱
 ↓ 重力

情况1：UV从左到右展开
  - 切线T指向右
  - 流动方向：切线空间 (正值, 0)
  - 结果：流体向右流动 ✓

情况2：UV从右到左展开
  - 切线T指向左
  - 流动方向：切线空间 (负值, 0)
  - 结果：流体向左流动 ✓

两种UV展开方式，流动方向都正确！
因为流动方向只取决于"下坡"，不取决于UV方向。
```

## 4. 实现细节

### 4.1 UV到三角形的映射

**问题**：给定UV坐标，找到对应的三角形。

**方案**：空间索引加速

```csharp
// 将UV空间划分为网格
int gridSize = resolution / 32;

// 为每个网格单元记录覆盖它的三角形
Dictionary<Vector2Int, List<int>> spatialIndex;

// 查找时
Vector2Int cell = new Vector2Int(uv.x * gridSize, uv.y * gridSize);
List<int> candidates = spatialIndex[cell];
// 只检查候选三角形，而不是所有三角形
```

### 4.2 重心坐标插值

**问题**：三角形内部任意点的属性如何计算？

**方案**：重心坐标插值

```
三角形顶点：A, B, C
重心坐标：(u, v, w)，其中 u + v + w = 1

任意属性 P = P_A × u + P_B × v + P_C × w

对于法线：
N = normalize(N_A × u + N_B × v + N_C × w)

对于切线：
T = normalize(T_A × u + T_B × v + T_C × w)
w分量 = sign(w_A × u + w_B × v + w_C × w)
```

### 4.3 边缘扩展算法

**问题**：UV岛边缘可能因为采样精度问题产生缝隙。

**方案**：迭代扩散

```
迭代 padding 次：
    对于每个无效像素：
        检查8邻域
        如果有有效邻居：
            复制最近邻居的值
            标记为扩展像素（A=0.5）
```

**效果**：
```
原始UV岛：          扩展后：
┌─────────┐        ┌───────────┐
│         │        │░░░░░░░░░░░│ ← 扩展区域
│  有效   │   →    │░░有效区域░│
│  区域   │        │░░░░░░░░░░░│
│         │        │░░░░░░░░░░░│
└─────────┘        └───────────┘
```

## 6. 在Shader中使用

### 6.1 采样并解码

```hlsl
// 采样重力图
float4 gravityData = GravityMap.SampleLevel(sampler, uv, 0);

// 解码方向（如果使用了[0,1]映射）
float2 flowDir = gravityData.xy * 2.0 - 1.0;

// 或者（如果保留原始值）
float2 flowDir = gravityData.xy;

// 获取强度（仅表面流动模式）
float intensity = gravityData.z;

// 检查是否有效
float isValid = gravityData.a;
```

### 6.2 应用到流体

```hlsl
// 流体速度更新
float2 velocity = ...; // 当前速度

// 添加重力驱动
velocity += flowDir * gravityStrength * dt * intensity;

// 或者直接设置方向
velocity = length(velocity) * normalize(flowDir);
```

## 7. 数学推导

### 7.1 TBN矩阵的构建

给定：
- 法线 N（单位向量）
- 切线 T（单位向量，沿UV的U方向）
- 副切线方向标记 w（±1，决定B的方向）

计算副切线：
```
B = (N × T) × w
```

注意：w来自切线的第四分量，用于处理UV镜像翻转的情况。

### 7.2 正交矩阵的性质

TBN是正交矩阵，满足：
```
TBN × TBN^T = I
TBN^(-1) = TBN^T
```

因此，从世界空间到切线空间的变换：
```
V_tangent = TBN^T × V_world
          = (V·T, V·B, V·N)
```

### 7.3 投影公式推导

重力在切平面上的投影：
```
G_proj = G - (G·N) × N

证明：
设 G = G_∥ + G_⊥
其中 G_∥ 在切平面内，G_⊥ 垂直于切平面

则 G_⊥ = (G·N) × N
所以 G_∥ = G - G_⊥ = G - (G·N) × N
```

## 8. 常见问题

### Q1: 为什么生成的方向看起来不对？

**可能原因**：
1. 使用了"切线空间重力"模式而不是"表面流动"模式
2. UV展开方向与预期不符
3. 模型没有正确的切线数据

**解决方案**：
- 使用"表面流动"模式
- 检查模型的切线数据（导入设置中勾选Tangents）

### Q2: 边缘有缝隙怎么办？

**解决方案**：
- 增加边缘扩展像素数（edgePadding）
- 使用更高的纹理分辨率

### Q3: 如何验证结果正确？

**方法**：
1. 使用"LogSamplePoints"调试模式查看详细计算过程
2. 在Scene视图中观察生成的预览
3. 用简单模型（球体、平面）测试

## 11. 总结

本工具通过预计算的方式，将世界空间的重力方向转换到切线空间，并烘焙为纹理。主要优势：

1. **精度高**：基于实际网格数据计算
2. **运行时开销小**：只需采样纹理
3. **灵活性强**：支持多种输出格式和参数
4. **与UV无关**：表面流动模式不受UV展开方式影响

适用于表面流体模拟、雨水效果、任意曲面上的方向控制等场景。
