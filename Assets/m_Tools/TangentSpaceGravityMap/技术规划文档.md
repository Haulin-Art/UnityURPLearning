# 切线空间重力梯度图生成工具 - 技术规划文档

## 1. 项目概述

### 1.1 目标
在Unity中开发一个编辑器工具，根据网格物体(Mesh)数据生成**切线空间重力方向贴图**，用于表面流体模拟中驱动水流方向。

### 1.2 输入与输出

| 项目 | 内容 |
|------|------|
| **输入** | Unity Mesh（顶点、法线、切线、UV坐标） |
| **输出** | 切线空间重力方向贴图（Texture2D），RG通道存储xy方向分量 |

### 1.3 应用场景
- 表面流体模拟中的重力驱动
- 雨水流动效果
- 任意曲面上的流体方向控制

## 2. 核心原理

### 2.1 坐标空间转换

```
世界空间重力方向 (0, -1, 0)
        ↓
    TBN逆矩阵变换
        ↓
切线空间重力方向 (Gx, Gy, Gz)
        ↓
   提取xy分量，映射到[0,1]
        ↓
   写入纹理RG通道
```

### 2.2 TBN矩阵

TBN矩阵由三个正交基向量组成：
- **T (Tangent)**: 切线，沿UV的U方向
- **B (Bitangent)**: 副切线，沿UV的V方向  
- **N (Normal)**: 法线，垂直于表面

```
TBN矩阵（世界空间到切线空间）:
| Tx Ty Tz |
| Bx By Bz |
| Nx Ny Nz |

由于TBN是正交矩阵，其逆矩阵等于转置矩阵：
TBN^(-1) = TBN^T
```

### 2.3 重力方向转换公式

```csharp
// 世界空间重力方向（Y轴负方向）
Vector3 worldGravity = Vector3.down; // (0, -1, 0)

// 构建TBN矩阵
Vector3 T = tangent.normalized;
Vector3 N = normal.normalized;
Vector3 B = Vector3.Cross(N, T) * tangent.w; // tangent.w存储了副切线方向

// 切线空间重力 = TBN转置 × 世界空间重力
// 等价于：分别与T、B、N点积
float Gx = Vector3.Dot(worldGravity, T);  // 重力在切线方向的分量
float Gy = Vector3.Dot(worldGravity, B);  // 重力在副切线方向的分量
float Gz = Vector3.Dot(worldGravity, N);  // 重力在法线方向的分量（通常用于判断是否朝上）

// 最终输出：只需要xy分量
Vector2 tangentGravity = new Vector2(Gx, Gy);
```

### 2.4 纹理编码格式

| 通道 | 内容 | 说明 |
|------|------|------|
| **R** | 切线空间重力X | 重力在切线方向的分量，映射到[0,1] |
| **G** | 切线空间重力Y | 重力在副切线方向的分量，映射到[0,1] |
| **B** | 可选：法线方向分量 | 用于判断表面朝向（正值表示朝上） |
| **A** | 可选：有效区域遮罩 | 1表示有效UV区域，0表示无效 |

### 2.5 可视化示意

```
球体表面的切线空间重力方向：

        顶点 (Gx=0, Gy=0)
           ↑
         /   \
        /     \    ← 侧面：重力沿切线方向滑落
       |       |
       |-------|   ← 赤道：重力完全沿切线方向
        \     /
         \   /
           ↓
        底点 (Gx=0, Gy=0)

颜色编码：
- 红色：重力向右(+X切线方向)
- 绿色：重力向上(+Y切线方向)
- 黑色：重力垂直于表面（顶点/底点）
```

## 3. 算法设计

### 3.1 核心流程

```
┌────────────────────────────────────────────────────────────┐
│ Step 1: UV空间遍历                                         │
│   - 遍历纹理的每个纹素                                      │
│   - 获取纹素中心对应的UV坐标                                │
└────────────────────────────────────────────────────────────┘
                              ↓
┌────────────────────────────────────────────────────────────┐
│ Step 2: UV到3D表面映射                                     │
│   - 通过射线投射或重心坐标插值                              │
│   - 找到UV对应的三角形和重心坐标                            │
│   - 插值计算该点的法线和切线                                │
└────────────────────────────────────────────────────────────┘
                              ↓
┌────────────────────────────────────────────────────────────┐
│ Step 3: 计算切线空间重力                                   │
│   - 构建TBN矩阵                                            │
│   - 转换世界空间重力到切线空间                              │
│   - 提取xy分量并映射到[0,1]                                │
└────────────────────────────────────────────────────────────┘
                              ↓
┌────────────────────────────────────────────────────────────┐
│ Step 4: 写入纹理                                           │
│   - 将计算结果写入对应纹素                                  │
│   - 处理UV岛边界和无效区域                                  │
└────────────────────────────────────────────────────────────┘
```

### 3.3 重心坐标插值

```csharp
// 插值计算任意点的属性
Vector3 InterpolateAttribute(Vector3 a, Vector3 b, Vector3 c, Vector3 barycentric) {
    return a * barycentric.x + b * barycentric.y + c * barycentric.z;
}

// 插值法线（需要归一化）
Vector3 InterpolateNormal(Vector3 n0, Vector3 n1, Vector3 n2, Vector3 barycentric) {
    Vector3 normal = InterpolateAttribute(n0, n1, n2, barycentric);
    return normal.normalized;
}

// 插值切线（需要归一化）
Vector4 InterpolateTangent(Vector4 t0, Vector4 t1, Vector4 t2, Vector3 barycentric) {
    Vector3 tangent = InterpolateAttribute(
        new Vector3(t0.x, t0.y, t0.z),
        new Vector3(t1.x, t1.y, t1.z),
        new Vector3(t2.x, t2.y, t2.z),
        barycentric
    ).normalized;
    
    // w分量也需要插值
    float w = t0.w * barycentric.x + t1.w * barycentric.y + t2.w * barycentric.z;
    
    return new Vector4(tangent.x, tangent.y, tangent.z, w >= 0 ? 1f : -1f);
}
```

## 8. 潜在问题与解决方案

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| UV接缝处数据不一致 | 不同三角形可能有不同的切线 | 使用统一的切线计算方法 |
| 部分像素无数据 | UV空间有空白区域 | 标记为无效区域（A=0） |
| 精度丢失 | PNG格式精度有限 | 默认使用EXR格式 |
| 性能问题 | 高分辨率纹理遍历慢 | 使用并行处理优化 |

## 9. 与现有系统的集成

### 9.1 输出格式兼容

生成的重力图格式与现有 `ShallowFluid.compute` 完全兼容：

```hlsl
// ShallowFluid.compute 中的采样代码
float2 gravityDir = GravityMap.SampleLevel(samplerLinearClamp, uv, 0).xy;
gravityDir = gravityDir * 2.0 - 1.0;  // 映射到[-1, 1]
```

### 9.2 使用流程

1. 使用本工具生成重力图
2. 在 `ShallowFluidSimulation` 组件中设置 `gravityMap`
3. 勾选 `useGravityMap` 启用功能
4. 调整 `gravityStrength` 控制重力强度
