# Unity UV岛邻接图生成工具 - 技术实现规划

## 1. 项目概述

### 1.1 目标
在Unity中开发一个工具，根据网格物体(Mesh)数据生成**UV邻接纹理**，用于表面流体模拟时实现跨UV岛的无缝流动。

### 1.2 输入与输出

| 项目 | 内容 |
|------|------|
| **输入** | Unity Mesh（顶点、三角形索引、UV坐标） |
| **输出** | UV邻接纹理（Texture2D），编码了UV岛边缘的邻接信息 |

### 1.3 应用场景
- 表面流体/纹理跨UV岛流动
- UV岛跳跃效果（UV Island Hopping）
- 无接缝程序化纹理生成

## 2. 输出效果详解

### 2.1 UV邻接纹理概念

```
原始UV布局                    UV邻接纹理输出
┌─────────────────────┐      ┌─────────────────────┐
│   ┌───┐             │      │   ┌───┐             │
│   │ A │   ┌───┐     │      │   │边缘│   ┌───┐   │
│   └─┬─┘   │ B │     │  →   │   │存B的│   │ B │   │
│     │     └───┘     │      │   │UV  │   └───┘   │
│   ┌─┴─┐             │      │   └───┘             │
│   │ C │             │      │   ┌───┐             │
│   └───┘             │      │   │ C │             │
└─────────────────────┘      └─────────────────────┘

在A岛边缘的像素中存储：
- R通道 = 邻接岛(B)对应位置的UV.x
- G通道 = 邻接岛(B)对应位置的UV.y
- B通道 = 到边缘的距离（用于混合权重）
- A通道 = 邻接岛ID（用于区分多个邻接）
```

### 2.2 纹理编码格式

| 通道 | 内容 | 说明 |
|------|------|------|
| **R** | 邻接UV.x | 邻接岛对应位置的UV坐标X分量 |
| **G** | 邻接UV.y | 邻接岛对应位置的UV坐标Y分量 |
| **B** | 混合权重 | 到边缘的距离（0=边缘，1=远离边缘） |
| **A** | 邻接岛ID | 用于多邻接情况区分（0表示无邻接） |

### 2.3 实际应用示例

```hlsl
// 着色器中的使用
float4 adjacencyData = _AdjacencyMap.Sample(sampler, uv);

if (adjacencyData.a > 0) {
    // 获取邻接UV坐标
    float2 adjacentUV = adjacencyData.rg;
    float blendWeight = 1.0 - adjacencyData.b;  // 边缘处权重高
    
    // 采样邻接岛的颜色
    float4 adjacentColor = _MainTex.Sample(sampler, adjacentUV);
    
    // 混合实现无缝过渡
    color = lerp(color, adjacentColor, blendWeight * _BlendStrength);
}
```

- UV岛内部：黑色（R=0, G=0, B=1, A=0）

## 3. 简化算法设计

### 3.1 核心思路

**关键洞察**：Unity Mesh的三角形索引本身就包含了完整的拓扑信息！

```
三角形A的边: 顶点(5, 8)  UV坐标(uv1, uv2)
三角形B的边: 顶点(8, 5)  UV坐标(uv3, uv4)
                    ↓
         顶点索引相同（顺序相反）= 3D空间同一条边
                    ↓
         UV坐标不同 = UV接缝 = 需要记录邻接关系！
```

### 3.2 算法流程（仅3步）

```
┌────────────────────────────────────────────────────────────┐
│ Step 1: 收集所有边并按顶点索引分组                           │
│   遍历所有三角形，记录每条边：                               │
│   - 顶点索引对 (vA, vB)                                    │
│   - 所属三角形索引                                          │
│   - UV坐标对 (uvA, uvB)                                    │
│   - 使用 (min(vA,vB), max(vA,vB)) 作为分组Key              │
└────────────────────────────────────────────────────────────┘
                              ↓
┌────────────────────────────────────────────────────────────┐
│ Step 2: 识别UV接缝                                         │
│   对于每组共享顶点的边：                                     │
│   - 只有1条边 → 网格边界，跳过                              │
│   - 有2条边且UV不连续 → UV接缝，记录邻接关系                 │
│   - 有2条边且UV连续 → 非接缝，跳过                          │
└────────────────────────────────────────────────────────────┘
                              ↓
┌────────────────────────────────────────────────────────────┐
│ Step 3: 烘焙到纹理                                         │
│   - 创建指定分辨率的纹理                                    │
│   - 光栅化UV三角形到纹理                                    │
│   - 在UV岛边缘像素写入邻接UV信息                            │
│   - 计算到边缘的距离作为混合权重                             │
└────────────────────────────────────────────────────────────┘
```

### 3.3 UV连续性判断

```csharp
// 判断两条边是否UV连续
bool AreUVsContinuous(EdgeInfo edgeA, EdgeInfo edgeB, float epsilon = 0.001f) {
    // 获取两条边的UV坐标
    Vector2 uvA1 = edgeA.uv1, uvA2 = edgeA.uv2;
    Vector2 uvB1 = edgeB.uv1, uvB2 = edgeB.uv2;
    
    // 检查UV是否匹配（考虑顶点顺序可能相反）
    bool match1 = Vector2.Distance(uvA1, uvB1) < epsilon && 
                  Vector2.Distance(uvA2, uvB2) < epsilon;
    bool match2 = Vector2.Distance(uvA1, uvB2) < epsilon && 
                  Vector2.Distance(uvA2, uvB1) < epsilon;
    
    return match1 || match2;
}
```

### 3.4 边缘UV映射计算

```csharp
// 计算边A上的点对应边B上的UV坐标
Vector2 MapUVAcrossSeam(Vector2 uvOnEdgeA, EdgeInfo edgeA, EdgeInfo edgeB) {
    // 计算点在边A上的参数t (0~1)
    float t = GetParameterOnEdge(uvOnEdgeA, edgeA.uv1, edgeA.uv2);
    
    // 找到边A和边B的顶点对应关系
    bool reversed = DetermineVertexCorrespondence(edgeA, edgeB);
    
    // 在边B上找到对应的UV坐标
    if (reversed) {
        return Vector2.Lerp(edgeB.uv2, edgeB.uv1, t);
    } else {
        return Vector2.Lerp(edgeB.uv1, edgeB.uv2, t);
    }
}
```

public class UVAdjacencyMapBuilder {
    // 边信息结构
    public struct EdgeInfo {
        public int vertexA, vertexB;      // 顶点索引
        public int triangleIndex;          // 所属三角形
        public int localEdgeIndex;         // 在三角形中的边索引(0,1,2)
        public Vector2 uvA, uvB;           // UV坐标
    }
    
    // 接缝邻接信息
    public struct SeamAdjacency {
        public EdgeInfo edgeA, edgeB;      // 邻接的两条边

    }
    
    // 主构建方法
    public static List<SeamAdjacency> Build(Mesh mesh, int uvChannel = 0);
    
    // 辅助方法
    private static List<EdgeInfo> ExtractAllEdges(Mesh mesh, int uvChannel);

}

## 8. 潜在问题与解决方案

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| UV接缝检测不准确 | UV浮点误差 | 使用适当的epsilon值（默认0.001） |
| 边缘像素遗漏 | 光栅化精度 | 增加edgePadding参数 |
| 多邻接角点处理 | 角点有多个邻接 | 只存储最近的邻接UV |
| 纹理分辨率不足 | 边缘细节丢失 | 提高分辨率或自适应分辨率 |
