# 高级阵列化渲染工具 - 技术规划文档

## 一、项目概述

### 1.1 项目目标
创建一个高性能的阵列化渲染工具，支持大规模实例渲染，具备GPU驱动的视锥剔除与HZB遮挡剔除功能。

### 1.2 与现有工具对比

| 特性 | 现有ArrayDistribution | 新工具 AdvancedArrayDistribution |
|------|----------------------|----------------------------------|
| 渲染方式 | DrawMeshInstanced | DrawMeshInstancedIndirect |
| 数据存储 | Matrix4x4[] (CPU) | ComputeBuffer (GPU) |
| 视锥剔除 | 无 | GPU Compute Shader |
| 遮挡剔除 | 无 | HZB遮挡剔除 |
| 数据更新 | 每帧CPU计算 | GPU并行计算 |
| 实例上限 | ~1023 | 几乎无限制 |

#### 步骤2.2：实现视锥剔除
**任务内容**：
- 传入相机VP矩阵
- 实现视锥剔除算法（参考 `grassPosCS.compute` 中的 `FrustumCulling` 函数）
- 将世界坐标转换到裁剪空间进行判断

**剔除算法**：
```hlsl
// 视锥剔除核心逻辑
bool FrustumCulling(float3 positionWS, float4x4 vpMatrix)
{
    float4 clipPos = mul(vpMatrix, float4(positionWS, 1.0));
    float4 absPos = abs(clipPos);
    
    // 检查是否在视锥体内
    return clipPos.z >= 0.0 &&
           absPos.x <= absPos.w * margin.x &&
           absPos.y <= absPos.w * margin.y &&
           clipPos.z <= clipPos.w * margin.z;
}
```

**Debug方法**：
- `FrustumCullingOnly`: 仅执行视锥剔除
- 输出剔除前后的实例计数
- 可视化：将剔除后的实例位置渲染为点

**产出文件**：
- 更新 `CullingCompute.compute`

---

#### 步骤2.3：实现HZB遮挡剔除
**任务内容**：

- 选择合适的Mip层级进行深度比较

**HZB采样策略**：
```hlsl
// HZB遮挡剔除核心逻辑
bool OcclusionCullingHZB(float3 positionWS, float3 boundsExtent)
{
    // 1. 计算AABB的8个角点到裁剪空间
    // 2. 计算屏幕空间AABB
    // 3. 选择合适的Mip层级
    // 4. 采样HZB深度并比较

```

## 四、关键技术细节

### 4.1 HZB纹理获取

HiZGenerationPass 在执行时会将纹理设置为全局Shader变量：

```csharp
// HiZGenerationPass.cs 中的关键代码
cmd.SetGlobalTexture("_HiZDepthTexture", hiZDepthRT);
for (int i = 0; i < mipCount; i++)
{
    cmd.SetGlobalTexture($"_HiZMip{i}Texture", hiZMipRTs[i]);
}
```

在Compute Shader中访问：
```hlsl
// 声明纹理
Texture2D<float> _HiZDepthTexture;
Texture2D<float> _HiZMip0Texture;
Texture2D<float> _HiZMip1Texture;
// ... 更多Mip层级

SamplerState sampler_HiZDepthTexture; // 或自定义采样器
```

### 4.2 间接绘制参数

`DrawMeshInstancedIndirect` 需要一个包含5个uint的ArgsBuffer：
```csharp
// ArgsBuffer布局：
// [0] - 每个Mesh的索引数（mesh.GetIndexCount(0)）
// [1] - 实例数量（由Compute Shader写入）
// [2] - 起始索引位置（mesh.GetIndexStart(0)）
// [3] - 起始顶点位置（mesh.GetBaseVertex(0)）
// [4] - 起始实例位置（通常为0）
```

### 4.3 剔除流程时序

```
帧开始
    │
    ▼
HiZGenerationPass 执行（生成HZB）
    │
    ▼
AdvancedArrayDistribution.LateUpdate
    │
    ├─► Dispatch CullingCompute
    │       │
    │       ├─► 视锥剔除
    │       │
    │       └─► HZB遮挡剔除
    │
    └─► DrawMeshInstancedIndirect
```

**重要**：确保HiZGenerationPass的 `renderPassEvent` 设置正确，使其在剔除计算之前完成HZB生成。

## 七、风险与备选方案

### 7.1 潜在风险

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| HZB纹理时序不同步 | 剔除结果错误 | 确保Pass执行顺序正确 |
| Compute Shader兼容性 | 部分平台不支持 | 提供CPU剔除回退方案 |
| 内存占用过大 | 性能下降 | 实现分块加载 |

### 7.2 备选方案

1. **CPU剔除回退**：在不支持Compute Shader的平台使用CPU剔除
2. **简化遮挡剔除**：使用简单的深度纹理代替HZB
3. **分帧剔除**：将剔除计算分散到多帧执行
