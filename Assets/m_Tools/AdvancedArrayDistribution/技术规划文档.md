# 高级阵列化渲染工具 - 技术规划文档

## 一、项目概述

### 1.1 项目目标
创建一个高性能的阵列化渲染工具，支持大规模实例渲染，具备GPU驱动的视锥剔除与HZB遮挡剔除功能。

### 1.2 与现有工具对比

| 特性 | 现有ArrayDistribution | 新工具 AdvancedArrayDistribution |
|------|----------------------|----------------------------------|
| 渲染方式 | DrawMeshInstanced | DrawMeshInstancedIndirect |
| 数据存储 | Matrix4x4[] (CPU) | ComputeBuffer (GPU) |
| 视锥剔除 | 无 | GPU Compute Shader |
| 遮挡剔除 | 无 | HZB遮挡剔除 |
| 数据更新 | 每帧CPU计算 | GPU并行计算 |
| 实例上限 | ~1023 | 几乎无限制 |

## 三、分步实现计划

### 第一阶段：基础Indirect实例绘制框架

#### 步骤1.1：创建主组件与Compute Shader基础框架
**任务内容**：
- 创建 `AdvancedArrayDistribution.cs` 主组件
  - 定义基础参数（网格、材质、阵列尺寸、间距等）
  - 定义 `DebugMode` 枚举用于调试
  - 实现资源初始化与释放逻辑
- 创建 `InstanceDataCompute.compute` Compute Shader
  - 定义实例数据结构 `InstanceData`（仅包含位置）
  - 定义输入参数（阵列尺寸、间距、偏移等）
  - 定义输出Buffer（实例位置数据）
  - 实现基础Kernel：`GenerateInstances`（仅计算位置，不做剔除）
- 创建 `AdvancedArrayInstanced.shader` 渲染Shader
  - 支持从ComputeBuffer读取实例位置
  - 缩放和旋转作为uniform参数传入
  - 基础的ForwardLit Pass

**数据结构定义**：
```csharp
// 实例数据结构（仅位置，简化Buffer大小）
public struct InstanceData
{
    public Vector3 position;    // 世界位置
    // 缩放和旋转作为uniform参数传入shader，不需要每个实例存储
}
```

**Compute Shader Kernel规划**：
```hlsl
#pragma kernel GenerateInstances      // 步骤1.1：生成所有实例位置
#pragma kernel CullingAndCount        // 步骤2.x：视锥+遮挡剔除合并（后续添加）
#pragma kernel UpdateArgsBuffer       // 更新间接绘制参数
```

**Kernel设计说明**：
- **合并剔除Kernel的原因**：视锥剔除和遮挡剔除对同一实例进行判断，中间结果（是否可见）不需要持久化到全局内存，合并可减少内存读写和kernel切换开销
- **分离UpdateArgsBuffer**：需要在所有剔除完成后执行，且需要读取计数器结果

**Debug方法**：
- `None`: 正常渲染流程
- `LogInstanceCount`: 在Console输出实例总数和Buffer状态
- `RenderAllInstances`: 跳过剔除，直接绘制所有实例（验证基础绘制正确性）

**产出文件**：
- `AdvancedArrayDistribution.cs`
- `Compute/InstanceDataCompute.compute`
- `Shaders/AdvancedArrayInstanced.shader`

**验证标准**：
- 能够在Scene中看到正确数量的实例渲染
- 实例位置与间距参数正确
- Gizmos显示阵列范围
- Console能正确输出实例统计信息

### 第二阶段：Compute Shader剔除实现

#### 步骤2.1：实现合并的视锥与遮挡剔除
**任务内容**：
- 在 `InstanceDataCompute.compute` 中添加 `CullingAndCount` Kernel
- 传入相机VP矩阵
- 实现视锥剔除算法（参考 `grassPosCS.compute`）
- 采样全局HZB纹理实现遮挡剔除
- 使用原子计数器统计可见实例

**Compute Shader 访问全局纹理**：
```hlsl
// Compute Shader 可以直接访问通过 SetGlobalTexture 设置的全局纹理
// HiZGenerationPass 已设置以下全局纹理：
Texture2D<float> _HiZDepthTexture;    // 原始深度副本
Texture2D<float> _HiZMip0Texture;     // Mip层级0
Texture2D<float> _HiZMip1Texture;     // Mip层级1
// ... 更多Mip层级

SamplerState sampler_HiZDepthTexture; // 采样器
```

**剔除算法**：
```hlsl
// 合并的剔除Kernel - 单次处理一个实例
[numthreads(64,1,1)]
void CullingAndCount(uint3 id : SV_DispatchThreadID)
{
    // 1. 获取实例位置
    float3 positionWS = _InstanceDataBuffer[id.x].position;
    
    // 2. 视锥剔除
    bool frustumVisible = FrustumCulling(positionWS, _VPMatrix);
    
    // 3. 遮挡剔除（仅对通过视锥剔除的实例执行）
    bool occlusionVisible = true;
    if (frustumVisible)
    {
        occlusionVisible = OcclusionCullingHZB(positionWS);
    }
    
    // 4. 写入可见实例
    if (frustumVisible && occlusionVisible)
    {
        uint visibleIndex;
        InterlockedAdd(_VisibleCounter[0], 1, visibleIndex);
        _VisibleBuffer[visibleIndex] = _InstanceDataBuffer[id.x];
    }
}
```

**视锥剔除算法**：
```hlsl
bool FrustumCulling(float3 positionWS, float4x4 vpMatrix, float3 margin = float3(1.2, 1.5, 1.2))
{
    float4 clipPos = mul(vpMatrix, float4(positionWS, 1.0));
    float4 absPos = abs(clipPos);
    
    return clipPos.z >= 0.0 &&
           absPos.x <= absPos.w * margin.x &&
           absPos.y <= absPos.w * margin.y &&
           clipPos.z <= clipPos.w * margin.z;
}
```

**HZB遮挡剔除算法**：
```hlsl
bool OcclusionCullingHZB(float3 positionWS)
{
    // 1. 转换到裁剪空间
    float4 clipPos = mul(_VPMatrix, float4(positionWS, 1.0));
    
    // 2. 计算屏幕空间UV
    float2 screenUV = clipPos.xy / clipPos.w * 0.5 + 0.5;
    #if UNITY_UV_STARTS_AT_TOP
        screenUV.y = 1.0 - screenUV.y;
    #endif
    
    // 3. 计算视图空间深度
    float viewDepth = mul(_VMatrix, float4(positionWS, 1.0)).z;
    
    // 4. 选择Mip层级并采样HZB
    // 简化版：使用Mip0，后续可优化为根据屏幕空间大小选择
    float hzbDepth = _HiZMip0Texture.SampleLevel(sampler_HiZDepthTexture, screenUV, 0);
    
    // 5. 深度比较（HZB存储的是最大深度，如果实例深度大于HZB深度则可见）
    return viewDepth <= hzbDepth + _OcclusionBias;
}
```

**Debug方法**：
- `FrustumCullingOnly`: 仅执行视锥剔除（在Kernel中跳过遮挡剔除逻辑）
- `OcclusionCullingOnly`: 仅执行遮挡剔除（跳过视锥剔除逻辑）
- `ShowCullingStats`: 输出剔除前后的实例计数
- `ColorByCullingState`: 按剔除状态着色（可见=绿色，剔除=红色）

**产出文件**：
- 更新 `Compute/InstanceDataCompute.compute`
- 更新 `AdvancedArrayDistribution.cs`

**验证标准**：
- 视锥外的实例被正确剔除
- 被遮挡的实例被正确剔除
- 移动相机时剔除结果实时更新
- 统计数据与预期一致


### 4.2 Indirect绘制参数

`DrawMeshInstancedIndirect` 需要一个包含5个uint的ArgsBuffer：
```csharp
// ArgsBuffer布局：
// [0] - 每个Mesh的索引数（mesh.GetIndexCount(0)）
// [1] - 实例数量（由Compute Shader写入）
// [2] - 起始索引位置（mesh.GetIndexStart(0)）
// [3] - 起始顶点位置（mesh.GetBaseVertex(0)）
// [4] - 起始实例位置（通常为0）
```

### 4.3 ComputeBuffer使用

```csharp

ComputeBuffer counterBuffer;       // 原子计数器（1个uint）
```

### 4.5 剔除流程时序

```
帧开始
    │
    ▼
HiZGenerationPass 执行（生成HZB）- 由URP管线自动调用
    │
    │  设置全局纹理：_HiZDepthTexture, _HiZMip0Texture...
    │
    ▼
AdvancedArrayDistribution.LateUpdate
    │
    ├─► 设置Compute Shader参数（VP矩阵、V矩阵等）
    │
    ├─► Dispatch GenerateInstances（如果需要更新位置数据）
    │
    ├─► 重置计数器
    │
    ├─► Dispatch CullingAndCount（合并的视锥+遮挡剔除）
    │
    ├─► Dispatch UpdateArgsBuffer（更新间接绘制参数）
    │
    └─► DrawMeshInstancedIndirect
```

**重要**：HiZGenerationPass 需要在剔除计算之前完成HZB生成，需确保其 `renderPassEvent` 设置正确（建议 `AfterRenderingTransparents` 或更早）。

## 七、风险与备选方案

### 7.1 潜在风险

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| HZB纹理时序不同步 | 剔除结果错误 | 确保Pass执行顺序正确 |
| Compute Shader兼容性 | 部分平台不支持 | 提供CPU剔除回退方案 |
| 内存占用过大 | 性能下降 | 实现分块加载 |

### 7.2 备选方案

1. **CPU剔除回退**：在不支持Compute Shader的平台使用CPU剔除
2. **简化遮挡剔除**：使用简单的深度纹理代替HZB
3. **分帧剔除**：将剔除计算分散到多帧执行
